# 한국·미국 주식 CANSLIM + 밸류에이션 분석

종목명을 입력하면 **CANSLIM 7개 조건 판정 · 밸류에이션(PER·PSR·PEG·ROE·PBR) ·
밸류에이션 밴드 기반 목표주가(Bear/Base/Bull) · 규칙 기반 투자의견 · 데이터 검증 표**를
한 화면에서 보여주는 웹 도구입니다. 분석 방법은 사용자가 관리하는
[`docs/claude_project_instructions.md`](docs/claude_project_instructions.md) (지침 v3)를 따릅니다.

- **한국** (코스피·코스닥): 네이버 금융 — 종목명이나 6자리 코드로 검색
- **미국** (나스닥·NYSE 등): 야후 파이낸스 — 티커(AAPL)나 영문 회사명으로 검색

## 실행 방법

**`run.bat` 을 더블클릭**하면 브라우저가 자동으로 열립니다. 끄려면 검은 창에서 `Ctrl+C`.


## 화면 읽는 법

### CANSLIM 7개 조건

윌리엄 오닐이 만든 성장주 선별법입니다. 🟢 합격 / 🔴 불합격 / ⚪ 판단불가로 표시되며,
**7개 항목을 모두 합격해야 `CANSLIM 충족`**입니다. 각 항목은 세부 조건 여러 개로 이루어지고
전부 만족해야 합격입니다. 기준 원문과 문턱값은 [`docs/canslim_criteria.md`](docs/canslim_criteria.md)에 있습니다.

| | 뜻 | 이 도구의 판정 기준 (세부 조건 전부 만족) |
|---|---|---|
| **C** | 최근 분기 실적 | 분기 EPS 전년동기比 **+17% 이상이 2분기 연속** · 최근 분기 EPS가 **직전 분기보다 증가** · 분기 매출 전년동기比 **+25% 이상** |
| **A** | 연간 실적 | 연간 EPS 성장률 **+17% 이상** · 확정 연도 EPS가 **매년 증가** · ROE **17% 이상**(없으면 판단불가) |
| **N** | 새로운 변화 | 현재가가 **52주 최고가의 90% 이상** · **새로운 재료**(신제품·수주·증설·M&A·경영진 변경 등) **2건 이상** |
| **S** | 수급 | 최근 50거래일 **상승일 거래량 ÷ 하락일 거래량 1.2배 이상** · 최근 10일 평균 거래량이 **50일 평균의 1.2배 이상** |
| **L** | 주도주 여부 | 3·6·9·12개월 가중 수익률이 **지수보다 +20%p 이상** · 종목 수익률 **양수** · **현재가 > 50일선 > 200일선** |
| **I** | 기관·외국인 수급 | 외국인 소진율이 **60거래일 전보다 +0.5%p 이상** · 기관 누적 순매수 **양수** (미국은 판단불가) |
| **M** | 시장 방향 | 지수가 **50일선·200일선 위** · **50일선 > 200일선** · 최근 25거래일 **분산일 5일 미만** |

> **⚪ 판단불가는 불합격이 아니지만, 충족도 아닙니다.** 자료가 없어 못 본 항목이 하나라도 있으면
> `미충족 (자료 부족)`으로 표시합니다. 모르는 것을 틀렸다고 하지 않되, 모르는 채로 통과시키지도 않습니다.
> 전년 같은 분기가 적자였던 경우는 증가율 대신 **흑자 전환 여부**로 봅니다.
>
> **수익 증가 종목 표시** — C1·C2(전년比)는 못 넘었지만 직전 분기보다 EPS가 늘고 매출도 +25% 이상이면,
> 불합격이더라도 직전·최근 분기 EPS를 `수익증가 2,864원→6,993원`처럼 함께 보여줍니다.

### 주요 제품·서비스 매출 구성 (한국 종목만)

회사 매출이 어떤 제품·서비스에서 나오는지 **비중이 큰 순서**로 표로 보여주고, 1위에 ⭐를 붙입니다.
구분 단위는 회사가 공시한 그대로입니다 — 제품 단위로 공시하는 회사는 제품으로, 삼성전자처럼
부문으로 묶어 공시하는 회사는 부문 이름(DS·DX)으로 보입니다. 각 줄의 **설명** 칸은 네이버
기업개요 문장에서 자동으로 잘라낸 것이라(예: DS → "메모리 반도체와 Foundry 사업") 없을 수 있습니다.
출처는 비중(%)만 주므로, 금액은 **최근 확정 연간 매출 × 비중**으로 계산한 추정치입니다.
내부거래 조정 때문에 '기타'가 음수이거나 비중 합계가 100%와 다를 수 있습니다.
개별 제품의 이익률과 출시일은 회사가 공개하지 않는 정보라 제공하지 않으며,
미국 종목은 제품별 매출을 주는 무료 출처가 없어 이 표가 없습니다 (10-K 참고 안내만 표시).

### 밸류에이션 4개 열

| 열 | 뜻 | 신뢰도 |
|---|---|---|
| **현재** | 이미 발표된 최근 4개 분기 실적 기준 | 🟢 실적확정 |
| **Q+1** | 확정 3개 분기 + 다음 분기 컨센서스 | 🟡 컨센서스 |
| **Q+2** | 확정 2개 분기 + 컨센서스 2개 분기 (한국은 **역산한 추정치**) | 🟡 / 🟠 |
| **연간 선행** | 당해 연도 연간 컨센서스 | 🟡 컨센서스 |

**컨센서스**란 여러 증권사 애널리스트가 낸 실적 전망의 평균값입니다.

**왜 한국 Q+2만 신뢰도가 낮은가:** 네이버는 미래 분기 컨센서스를 **딱 하나만** 제공합니다.
그래서 한국 종목의 Q+2는 원본이 없어, 연간 컨센서스에서 이미 아는 분기를 빼고 남은 금액을
작년 같은 분기의 비중대로 나눠 **계산해서 뽑아낸 값**입니다(🟠 역산추정). 미국은 야후가
Q+1·Q+2 컨센서스를 원본으로 제공하므로 역산이 필요 없습니다.

**PEG는 성장률이 100%를 넘으면 표시하지 않습니다.** 극단적 고성장 구간에서 PEG는 0에
붙어 아무 정보도 주지 못하기 때문입니다(20~50% 성장 구간용 지표).

### 목표주가와 투자의견 (기계적 규칙)

- **밸류에이션 밴드**: 최근 3개 확정 연도 각각의 주가 고점·저점 ÷ 그 해 EPS → 멀티플 상단·하단.
  TTM 적자면 PER 대신 주당매출(PSR) 밴드. 적자 연도·거래일 부족 연도는 제외하고 사유를 표시합니다.
- **목표주가**: Bear = 밴드 하단 × min(TTM, 컨센서스 EPS) / Base = 중간 × 컨센서스 EPS /
  Bull = 상단 × 차년도 컨센서스 EPS. 멀티플 3단계 × 이익 3단계 민감도 표를 함께 보여줍니다.
- **투자의견 결합 규칙** (지침 v3 Step 10): CANSLIM이 1차, Base 괴리율이 2차 —
  매수(충족+괴리율>0) / 조건부 매수 후보(불합격 0·판단불가만+괴리율>0) / 중립 /
  매도·비중 축소(불합격 3개↑, M 불합격, C·L 동시 불합격, 괴리율 ≤ −20%).
- 이익이 급감했던 해가 밴드를 부풀리면 경고가 뜹니다. **전부 기계적 계산이며 매수·매도 신호가 아닙니다.**

### 데이터 검증 표

쓰인 수치를 항목별로 출처·신뢰도(🟢확인/🟡단일/🟠추정/⚫불가)와 함께 나열하고,
**주가 × 발행주식수 = 시가총액** 검산(5% 이내)과 자체 PER vs 출처 PER 교차검증을 수행합니다.

### 🤖 클로드 프로젝트에서 해석 이어가기

계산은 앱이, **해석(피어 비교·프리미엄/디스카운트·핵심 가정·촉매·리스크)은 클로드 프로젝트**가
맡는 구조입니다(클로드 구독 활용 — 추가 비용 없음). 앱이 만들어 주는 "앱 분석 요약"을 복사해
지침 v3가 들어 있는 클로드 프로젝트에 붙여넣으면, 수치 검색 없이 해석에 집중한 답을 받습니다.

### 지표 뜻

- **PER** = 주가 ÷ 주당순이익. 낮을수록 이익 대비 싸다는 뜻입니다.
- **PSR** = 시가총액 ÷ 매출액. 아직 이익이 안 나는 회사를 볼 때 씁니다.
- **PEG** = PER ÷ 이익성장률. **1보다 낮으면** 성장에 비해 주가가 싸다고 봅니다.
- **ROE** = 자기자본이익률. 회사가 자기 돈으로 얼마나 잘 버는지. 오닐은 17% 이상을 요구했습니다.

적자 기업의 PER처럼 **지표가 성립하지 않으면 `—`** 로 표시됩니다.

## 데이터 출처와 검증

한국은 **네이버 금융**, 미국은 **야후 파이낸스(yfinance)** 에서 받아옵니다.
로그인이나 API 키가 필요 없습니다.

우리가 계산한 PER을 출처가 직접 준 PER과 나란히 표시해 교차검증합니다.
2026-08-09 기준 삼성전자(18.67 = 네이버 18.67), 애플(35.93 ≈ 야후 35.97) 일치를 확인했습니다.
화면 상단에 **가격·재무·컨센서스 기준일**을 항상 표시합니다.

## 알아두실 한계

- **오닐 원본 RS Rating(1~99점)이 아닙니다.** `L`은 전 종목 백분위가 아니라 지수 대비 +20%p 초과 여부와
  종목 추세(현재가 > 50일선 > 200일선)입니다.
- **`M`의 분산일은 지수 거래량으로 셉니다.** 네이버(코스피·코스닥)와 야후(S&P500) 모두 지수 거래량을
  주지만, 없으면 분산일 조건은 판단불가가 됩니다.
- **`N`의 '새로운 재료'는 키워드 자동 분류입니다.** 최근 180일 공시·뉴스·리포트 **제목**만 보고
  분류하므로, 본문을 읽어야 알 수 있는 재료는 놓치고 제목만 그럴듯한 것은 잘못 잡을 수 있습니다.
  화면에 찾아낸 제목을 그대로 띄우니 직접 읽고 판단하세요.
- **`S`는 유통주식수(float)를 반영하지 못합니다.** 무료로 구할 수 없어 상승일/하락일 거래량 비율(매집)과
  최근 거래량 증가로 대체했고, 장중에는 부분 거래량 왜곡을 피하려고 직전 완결 거래일까지만 씁니다.
- **`I`** — 한국은 기관 보유 비중이 아니라 외국인 소진율 추세와 네이버가 주는 최근 5거래일 안팎의
  기관 누적 순매수, 미국은 기관 보유 비중의 시점값만 있어 판단불가 + 수치 표기입니다.
- **`C`의 C2(직전 분기 전년동기比)는 야후 실적 발표 이력으로 보강합니다.** 네이버·야후 재무표는 확정 분기를
  5개만 주는데 C2에는 6개가 필요합니다. 그래서 야후의 실적 발표 이력(Reported EPS, 한국 종목은 `005930.KS`
  처럼 조회)을 받아 `EPS(발표)` 행으로 붙이고, 겹치는 분기에서 재무표와 20% 넘게 다르면 버립니다.
  C1·C2는 이 행끼리만 비교해 출처 차이가 증가율에 섞이지 않게 합니다. 야후가 그 종목의 발표 이력을
  안 주거나(코스닥 일부) 조정 EPS라 재무표와 크게 다르면(예: 엔비디아) 보강하지 않고 C2는 판단불가로 남습니다.
  화면 CANSLIM 표 아래에 보강 여부를 표시합니다.
- **제품·서비스 매출 구성은 비중만 원본이고 금액은 추정치입니다.** 비중의 기준 시점(분기)과
  곱하는 연간 매출의 시점이 달라 오차가 있을 수 있습니다. 설명 칸은 기업개요 문장에서
  기계적으로 잘라낸 것이라 틀리거나 없을 수 있습니다. 개별 제품의 이익률·출시일은 어떤 무료
  출처도 구조화해 주지 않아(DART API에도 없음) 제공하지 않습니다.
- **목표주가·투자의견은 기계적 규칙의 결과입니다.** 일회성 이익이 밴드를 부풀릴 수 있고(경고 표시),
  업종 특성·경쟁 구도 같은 정성 요인은 반영하지 못합니다. FCF·순차입금·EV/EBITDA·유통주식수는
  무료 출처가 없어 '확인 불가'로 표기합니다.
- **한국의 최신 확정 분기는 한 분기 늦을 수 있습니다.** 잠정실적 발표 후 네이버 확정 재무
  반영까지 시차가 있습니다. (DART 잠정실적 연동은 API 키가 필요해 추후 과제)
- **연간 성장률** — 한국 2년(네이버 3개년), 미국 3년(야후 4개년) 기준입니다.
- **비공식 API에 의존합니다.** 네이버·야후가 형식을 바꾸면 동작하지 않을 수 있습니다.
- 애널리스트가 커버하지 않는 소형주는 **컨센서스가 없는 것이 정상**입니다.
