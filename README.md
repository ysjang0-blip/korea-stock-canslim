# 한국 주식 CANSLIM + 밸류에이션 분석

종목명을 입력하면 **CANSLIM 7개 조건 판정**과 **현재·예상 밸류에이션(PER·PSR·PEG·ROE)** 을
한 화면에서 보여주는 웹 도구입니다. 한국(코스피·코스닥) 종목 전용입니다.

## 실행 방법

**`run.bat` 을 더블클릭**하면 브라우저가 자동으로 열립니다. 끄려면 검은 창에서 `Ctrl+C`.

터미널에서 직접 실행하려면:

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

### 처음 설치할 때만

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 화면 읽는 법

### CANSLIM 7개 조건

윌리엄 오닐이 만든 성장주 선별법입니다. 🟢 합격 / 🔴 불합격 / ⚪ 판단불가로 표시됩니다.

| | 뜻 | 이 도구의 판정 기준 |
|---|---|---|
| **C** | 최근 분기 실적 | 분기 EPS가 전년 같은 분기보다 **+25% 이상** |
| **A** | 연간 실적 | 연간 EPS 성장률 **+25% 이상** **그리고** ROE **17% 이상** |
| **N** | 신고가 근접 | 현재가가 **52주 최고가의 85% 이상** |
| **S** | 수급 | 당일 거래량이 **50일 평균의 1.4배 이상** |
| **L** | 주도주 여부 | 3·6·9·12개월 가중 수익률이 **지수보다 높음** |
| **I** | 기관·외국인 수급 | 외국인 소진율이 **60거래일 전보다 상승** |
| **M** | 시장 방향 | 지수가 **50일선·200일선 위** |

> **⚪ 판단불가는 불합격이 아닙니다.** 예를 들어 작년 같은 분기가 적자였다면 "몇 % 성장"이라는
> 말 자체가 성립하지 않습니다. 이런 항목은 점수 분모에서 빼기 때문에 `3 / 6 통과` 처럼 표시됩니다.

### 밸류에이션 4개 열

| 열 | 뜻 | 신뢰도 |
|---|---|---|
| **현재** | 이미 발표된 최근 4개 분기 실적 기준 | 🟢 실적확정 |
| **Q+1** | 확정 3개 분기 + 다음 분기 컨센서스 | 🟡 컨센서스 |
| **Q+2** | 확정 2개 분기 + Q+1 컨센서스 + **역산한 추정치** | 🟠 역산추정 |
| **연간 선행** | 당해 연도 연간 컨센서스 | 🟡 컨센서스 |

**컨센서스**란 여러 증권사 애널리스트가 낸 실적 전망의 평균값입니다.

**왜 Q+2만 신뢰도가 낮은가:** 네이버는 미래 분기 컨센서스를 **딱 하나만** 제공합니다.
그래서 Q+2는 원본이 없어, 연간 컨센서스에서 이미 아는 분기를 빼고 남은 금액을
작년 같은 분기의 비중대로 나눠 **계산해서 뽑아낸 값**입니다. 추정에서 뽑은 추정입니다.

### 지표 뜻

- **PER** = 주가 ÷ 주당순이익. 낮을수록 이익 대비 싸다는 뜻입니다.
- **PSR** = 시가총액 ÷ 매출액. 아직 이익이 안 나는 회사를 볼 때 씁니다.
- **PEG** = PER ÷ 이익성장률. **1보다 낮으면** 성장에 비해 주가가 싸다고 봅니다.
- **ROE** = 자기자본이익률. 회사가 자기 돈으로 얼마나 잘 버는지. 오닐은 17% 이상을 요구했습니다.

적자 기업의 PER처럼 **지표가 성립하지 않으면 `—`** 로 표시됩니다.

src/charts.py       차트 (검증된 팔레트 사용)

## 알아두실 한계

- **오닐 원본 RS Rating(1~99점)이 아닙니다.** `L`은 전 종목 백분위가 아니라 지수 대비 초과 여부입니다.
- **`N`의 '신제품' 같은 질적 요소는 자동 판정 대상이 아닙니다.**
- **`S`는 유통주식수(float)를 반영하지 못합니다.** 무료로 구할 수 없어 거래량으로 대체했습니다.
- **`I`는 기관 보유 비중이 아니라 외국인 소진율 추세입니다.**
- **연간 성장률은 2년 기준입니다.** 네이버가 연간 데이터를 3개년만 줍니다.
- **비공식 API에 의존합니다.** 네이버가 형식을 바꾸면 동작하지 않을 수 있습니다.
- 애널리스트가 커버하지 않는 소형주는 **컨센서스가 없는 것이 정상**입니다.
